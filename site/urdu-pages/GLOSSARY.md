# Urdu glossary for uptrendpos.com (use these words on every Urdu page)

Write clear, simple, everyday Urdu that a shop owner in Pakistan reads easily. Short sentences.
Use common loanwords people already say (بلنگ، اسٹاک، انوائس، اپڈیٹ، ڈیمو) instead of heavy Persian/Arabic words.
Never Roman Urdu on the page (only the WhatsApp message text, which the tool sets).

## SEO in Urdu
- data-seo-title: 25-70 characters, Urdu, keep "| UpTrendPos" at the end, put the main Urdu keyword first (e.g. "کریانہ اسٹور کے لیے POS سافٹ ویئر").
- data-seo-desc: 100-165 characters, Urdu, says what the page gives + one benefit (offline / FBR / 7 دن مفت).
- data-seo-kw: 3-4 Urdu keyword phrases people type, comma separated (e.g. "کریانہ اسٹور سافٹ ویئر, POS سافٹ ویئر پاکستان, ادھار کھاتہ ایپ").
- Use the main Urdu keyword in the H1, the first paragraph and one H2; never stuff it.
